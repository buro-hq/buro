# Buro branding

The mark uses four connected workspaces, adapted from `public/icon.svg`. The name stays **Buro** across GitHub, the application and documentation.

| Asset | Use |
| --- | --- |
| `logo.svg` / `logo.png` | Logo with wordmark for light backgrounds; transparent |
| `logo-light.svg` / `logo-light.png` | Logo with wordmark for dark backgrounds; transparent |
| `mark.svg` / `mark.png` | Standalone mark; transparent |
| `github-avatar.png` | GitHub organization avatar, 1024 × 1024 |
| `github-avatar-512.png` | Smaller avatar, 512 × 512 |
| `github-avatar.svg` | Editable vector source for the avatar |

Upload `github-avatar.png` as the organization picture. Its solid background and centered mark also work with a circular crop. Use SVG for scalable layouts and PNG for upload forms. Wordmark letters are vector outlines, so the logo does not depend on installed fonts.

Colors: charcoal `#14191a`, sage `#bad3a2`, ink `#202c22`, green `#496d35`, off-white `#e8eee7`.

Keep the proportions and leave clear space around the mark. Do not stretch or add effects.
