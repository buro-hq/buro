Method and limitations

    

      Both checkouts start at 7738a09, use the same assignment and the code-style,
      architecture and Buro-architecture review profiles derived from the Desktop preference
      document. Each flow receives three independent reviewers and automatic correction, without a
      configured round cap.
    

    

      Buro runs official DeepSeek Flash with thinking/high, 128K context projection and 16K output
      reserve. Native Codex uses the local default GPT-6.1-Sol/high via CLI 0.172.0, native tools
      and native context management. This compares complete workflows; it does not isolate model
      intelligence. Native CLI turns are not comparable to individual Buro model requests. Saved
      implementation snapshots get the same independent lint/types/tests/build and feature API
      checks. Browser behavior still needs explicit recorded evidence.
    

    

      Flash cost uses actual returned cache-hit/miss/output usage and the

      these rates. November 26 is treated as an ordinary weekday, not a Chinese public holiday.
      Unreported canceled usage is excluded. Codex runs on account quota; no API dollar bill is
      invented.
