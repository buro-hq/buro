Method and limitations
Native Codex runs directly via its CLI in a separate checkout, alongside Buro. Flash had an initial solo stage; later CPU/tool activity overlaps, so wall times are not isolated measurements. Independent final checks run after model work ends. A zero-model-turn native network setup failure is archived separately and excluded from quality scoring.
Both checkouts start at 7738a09, use the same assignment and the code-style, architecture and Buro-architecture review profiles derived from the Desktop preference document. Each flow receives three independent reviewers and automatic correction, without a configured round cap.
Buro runs official DeepSeek Flash with thinking/high, 128K context projection and 16K output reserve. Native Codex uses the local default GPT-6.1-Sol/high via CLI 0.172.0, native tools and native context management. This compares complete workflows; it does not isolate model intelligence. Native CLI turns are not comparable to individual Buro model requests. Saved implementation snapshots get the same independent lint/types/tests/build and feature API checks. Browser behavior still needs explicit recorded evidence.
Flash cost uses actual returned cache-hit/miss/output usage and the official pricing checked November 26: off-peak $0.003/$0.15/$0.60 per million; weekday 01–04 and 06–10 UTC doubles these rates. November 26 is treated as an ordinary weekday, not a Chinese public holiday. Unreported canceled usage is excluded. Codex runs on account quota; no API dollar bill is invented.
